Check the file.
Then check the import.

A CSV can be well formed and still change the wrong thing in a store. Use this checklist to separate file errors from decisions that need Shopify’s importer, a backup and your own review.

1. Start from the right export

Keep an untouched copy of the catalog and record which store and export date it came from. Use the current Shopify CSV instructions for the fields you plan to update. Older templates use different heading names; do not assume that a valid-looking heading has the meaning you intend.

2. Check quoting before counting columns

A comma inside a quoted title is part of the title. Splitting every line on commas will incorrectly treat it as another field. Embedded quotes need escaping, and quoted fields can span physical lines. A useful report should tell you which physical line needs review.

Handle,Title,Variant Price,Option1 Value
linen-shirt,"Linen shirt, relaxed",29.00,Medium
linen-shirt,,EUR 29,Medium

This is a synthetic example, not a customer catalog. The quoted title is valid CSV. The second row has a price string to review and repeats the same handle-plus-option combination. Correct the intended price in your own editor; do not strip currency symbols or replace decimal separators blindly.

3. Review variants as combinations

Compare the product handle together with every option value. Two rows with the same combination need investigation. A repeated SKU alone is a warning, not proof of an invalid product. Additional image-only rows are different from variant records and should not be removed simply because they repeat a handle.

4. Separate price formatting from price meaning

Check the platform’s expected numeric format. A structurally valid number can still represent the wrong currency, wholesale cost or retail price. Compare a few intended prices against their source. This free checker flags some price strings; it does not infer currencies or business intent.

5. Test the change against the actual store

  1. Review which existing products and variants the identifiers refer to.
  2. Read the importer’s overwrite and blank-field behavior for your exact task.
  3. Test a small, recoverable batch and inspect the resulting products, options, images and inventory.
  4. Review the import log before sending a larger batch. A product export is not a complete store recovery plan.

Shopify documents common CSV import errors. A file-only checker cannot see existing store state or guarantee that variants will be preserved. If you already use an importer with a dry run, include it in your process; this page is not a replacement for that check.

6. Hand over a reviewable report

Record the check date, platform profile, rows flagged, checks omitted and the person responsible for reviewing changes. Share a report without product values when the recipient does not need the catalog itself. Keep the original file and the import log in your own approved storage.
