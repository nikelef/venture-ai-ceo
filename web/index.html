    02 / WHAT THIS CHECKS

    A useful first pass

    File structure
    Quoted fields, uneven records, duplicate or empty headings, and formula-like values.

    Catalog hints
    Current and legacy Shopify heading aliases, repeated SKUs, variant option collisions and price strings.

    A clean report does not guarantee import success. Store state, API validation, inventory locations, images and the full platform schema require separate checks. Repeated SKUs and formula-like text can be intentional. This tool cannot predict deleted variants or provide a rollback. Keep a backup and test a small batch before changing a store.
