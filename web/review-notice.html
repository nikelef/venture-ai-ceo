Research prototype

This evaluation tool processes chosen CSV files in your browser. Its code sends no file contents, reports or analytics to a server, and uses no cookies or browser storage. Downloaded reports contain diagnostic locations and codes, without source headings or cell values. Clear the page to release its current file and report.

If the tool is eventually hosted, the hosting provider may process ordinary connection logs, including IP addresses. Operator identity, hosting retention details and applicable privacy notices must be reviewed before public activation.
